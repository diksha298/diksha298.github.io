## 🚀 Deploy to GitHub Pages (step-by-step)

### Step 1 – Create a GitHub account
Go to **https://github.com** and sign up (free).

### Step 2 – Create a new repository
1. Click the **+** icon → **New repository**
2. Name it exactly: `dikshasoni-mehendi.github.io`
   *(Replace `dikshasoni-mehendi` with your GitHub username)*
3. Set to **Public**
4. Click **Create repository**

### Step 3 – Upload files via GitHub web UI (no coding needed)
1. Open your new repo on GitHub
2. Click **uploading an existing file** (or drag-and-drop)
3. Select **all files and folders** from this project:
   ```
   index.html
   reservation.html
   robots.txt
   sitemap.xml
   .gitignore
   css/
   js/
   images/
   videos/
   fonts/
   ```
4. Scroll down → click **Commit changes**

### Step 4 – Enable GitHub Pages
1. Go to your repo → **Settings** tab
2. Left sidebar → **Pages**
3. Under *Branch*, select **main** and folder **/ (root)**
4. Click **Save**

### Step 5 – Your site is live! 🎉
After ~60 seconds visit:
```
https://<your-github-username>.github.io/
```
